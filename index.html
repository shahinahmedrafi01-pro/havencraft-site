Frequently Asked Questions

Is Bedrock supported?

Yes! You can join using Minecraft Bedrock Edition with full Java & Bedrock crossplay. Use IP mc.havencraft.pro and port 2566.

Which Minecraft version can join?

The server supports versions 1.21 and above, so you get the best performance and the newest features.

Is PvP allowed?

PvP is enabled in specific zones and arenas, while survival builds stay protected from griefing.

How do I claim land?

We use a simple claim plugin — use a golden shovel to select the corners of your land and protect it from griefers.
