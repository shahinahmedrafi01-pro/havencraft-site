1. নির্বাহী সারসংক্ষেপ (Executive Summary)

HavenCraft SMP বাংলাদেশের অন্যতম প্রিমিয়াম ক্রসপ্লে মাইনক্রাফট সার্ভার। বর্তমান হোমপেজে চমৎকার ডার্ক থিম, সায়ান/মিন্ট গ্রিন কালার প্যালেট এবং রেসপনসিভ গ্রিড থাকা সত্ত্বেও তিনটি বড় UX বাধা রয়েছে:

  1. ব্র্যান্ডিং ও লোগো ডুপ্লিকেশন: স্ক্রিনের উপরে হেডারে ছোট লোগো, আবার তার ঠিক নিচেই হিরোতে বিশাল লোগো—একই স্ক্রিনে দুবার একই পরিচিতি প্রদর্শিত হয়ে মূল্যবান ভার্টিক্যাল স্পেস নষ্ট করছে।
  2. ডেক্সটপে হরিজন্টাল স্পেস অপচয়: সব উপাদান (লোগো, টাইটেল, কার্ড, বাটন) সেন্ট্রাল অ্যালাইন করায় বড় স্ক্রিনের বাম ও ডান পাশ পুরোপুরি ফাঁকা ও নিরুত্তাপ লাগে।
  3. কানেকশন অ্যাকশনের গুরুত্বের ঘাটতি: মাইনক্রাফট সার্ভার ওয়েবসাইটে ভিজিটর আসার মূল উদ্দেশ্য সার্ভারে জয়েন করা। অথচ বর্তমান ডিজাইনে ৪টি স্ট্যাটাস কার্ড পার হওয়ার পর সার্ভার আইপি চোখে পড়ে, এবং বেডরক প্লেয়ারদের জন্য পোর্ট (2566) আলাদাভাবে স্পষ্ট নয়।

আপনার নিজের মূল আইডিয়াটি ছিল: "হিরো সেকশনের লোগোটি বামে নেওয়া এবং ইউজার স্ক্রল করলে সেটি স্মুথলি হেডারে চলে যাওয়া।"

ChatGPT এবং Gemini Argon উভয়েই আপনার আইডিয়ার সম্ভাব্য সৌন্দর্য উপলব্ধি করেছে, তবে দুটি ভিন্ন কোণ থেকে মতামত দিয়েছে। নিচে তাদের মতামতের দুর্বলতা ও শক্তির সমন্বয় করে HavenCraft-এর জন্য একটি আন্তর্জাতিক মানের "Master UI/UX Architecture" উপস্থাপন করা হলো।

2. ChatGPT বনাম Gemini Argon: নিরপেক্ষ চুলচেরা বিশ্লেষণ

বিচার্য বিষয় ChatGPT-এর দৃষ্টিভঙ্গি (ChatGPT.md) Gemini Argon-এর দৃষ্টিভঙ্গি (Gemini.md) Antigravity-র বাস্তবসম্মত মূল্যায়ন
মূল দর্শন প্র্যাগম্যাটিক ও কনভার্সন-ফার্স্ট: অপ্রয়োজনীয় অ্যানিমেশন পরিহার এবং সেফ লেআউট। অ্যাম্বিশিয়াস ও এস্থেটিক-ফার্স্ট: ভিজ্যুয়াল ওয়াও-ফ্যাক্টর ও হাই-বাজেট লুক। দুটিই আংশিক সত্য। শুধু সেফ ডিজাইন ওয়েবসাইটকে সাধারণ বানিয়ে ফেলে, আবার অতি-অ্যানিমেশন পারফরম্যান্স ও ফ্রেমরেট নষ্ট করে। আমাদের দরকার "High Aesthetics with Zero Performance Cost"।
লোগো স্ক্রল অ্যানিমেশন সতর্ক ও নিরুৎসাহিত: হেডারে সবসময় লোগো রাখার পক্ষে (Option B)। অ্যানিমেশনে লেআউট শিফট হওয়ার ঝুঁকি দেখেছে। পূর্ণ সমর্থন: ৩টি সুন্দর আইডিয়া দিয়েছে (Floating Pill, Live Badge, Visual Balance)। জেমিনির Floating Pill ও Live Badge আইডিয়া অত্যন্ত চমৎকার! তবে চ্যাটজিপিটির সতর্কতাও সত্য—navbar.js যেহেতু ১৫+ পেজে ব্যবহৃত, তাই গ্লোবাল ন্যাভবার নষ্ট না করে কীভাবে করা যায় তা জেমিনি বলেনি।
হিরো লেআউট Desktop Split Layout: বামে লোগো ও টাইটেল, ডানে লাইভ স্ট্যাটাস প্যানেল। 50/50 Split Grid: বামে ব্র্যান্ডিং ও বাটন, ডানে ২x২ কার্ড গ্রিড + আইপি কার্ড। জেমিনির 2x2 Grid + Dedicated Connection Card অনেক বেশি ব্যালেন্সড ও অর্গানাইজড। চ্যাটজিপিটির চেয়ে জেমিনির গ্রিড গঠন বেশি প্রফেশনাল।
সার্ভার আইপি ও পোর্ট আইপি কপি বাটন বড় করার কথা বললেও বেডরক পোর্টের কথা বলেনি। Java IP ও Bedrock Port আলাদা হাইলাইট করার প্রস্তাব দিয়েছে। জেমিনি এখানে ১০০% বিজয়ী। বাংলাদেশের ৬০%+ মাইনক্রাফট প্লেয়ার মোবাইল/বেডরকে খেলে। বেডরক পোর্ট (2566) আলাদা না থাকলে প্লেয়াররা ঢুকতে দ্বিধাদ্বন্দ্বে পড়ে।
ভিজ্যুয়াল গভীরতা ব্যাকগ্রাউন্ড নিয়ে কোনো মন্তব্য করেনি; শুধুই লেআউট বিন্যাস। ব্যাকগ্রাউন্ডে ইন-গেম স্পনের ব্লার স্ক্রিনশট ও কার্ডে হালকা গ্লো দেওয়ার কথা বলেছে। জেমিনির আইডিয়া অসাধারণ। পিচ-ব্ল্যাক স্ক্রিনে অ্যাম্বিয়েন্ট শট এবং নিয়ন গ্লো দিলে সাইট এক নিমেষে প্রিমিয়াম এস্পোর্টস সাইটের রূপ নেয়।

এই কাঠামোর মূল সাফল্য:

  1. হেডারের বাম পাশ কখনোই ফাঁকা লাগবে না: উপরে থাকার সময় সেখানে থাকবে লাইভ স্ট্যাটাস ব্যাজ (🟢 Server Online বা 🔥 Season 6)।
  2. লোগোর দ্বৈত উপস্থিতি বন্ধ: হিরোতে যখন বিশাল লোগো দৃশ্যমান, তখন হেডারে ডুপ্লিকেট লোগো থাকবে না।
  3. স্ক্রল ট্রানজিশনের বিস্ময়: স্ক্রল করার সাথে সাথেই ফ্লোটিং ক্যাপসুলটি পূর্ণ ন্যাভবারে পরিণত হবে এবং ব্র্যান্ড লোগো সেখানে স্থান গ্রহণ করবে (Apple ও Linear স্টাইল)।
  4. সার্ভার জয়েন করার সর্বোচ্চ গতি: নতুন প্লেয়ার এসেই ডানের টার্মিনালে জাভা ও বেডরক উভয় আইপি চোখের সামনে পাবে।

4. ন্যাভিগেশন সল্যুশন: Adaptive Floating Pill Header আর্কিটেকচার

ইউজারের মনে প্রশ্ন ছিল: "হেডার থেকে লোগো হিরোতে নিয়ে গেলে পেজের শুরুতে হেডারের বাম পাশটা কি খালি ও দেখতে অদ্ভুত লাগবে?"

সমাধান: একদমই অদ্ভুত লাগবে না, যদি আমরা "Dynamic Adaptive Island" মেথড ব্যবহার করি।

ক. পেজের শুরুতে (Initial View - Scroll Y = 0)

  • হেডার পুরো স্ক্রিন জুড়ে থাকবে না। এটি স্ক্রিনের টপে একটি সুন্দর Floating Pill Glass Island হিসেবে অবস্থান করবে (Width: ~88%, Max-width: 1100px, Border-radius: 9999px)।
  • বাম কোণায় (Brand Slot): লোগোর জায়গায় একটি স্টাইলিশ মিনি-চিপ থাকবে:
    <div class="nav-status-chip">
    <span class="pulse-emerald"></span>
    <span class="chip-text">1.21+ CROSSPLAY</span>
</div>
  • মাঝখানে: ন্যাভিগেশন মেনু আইটেম (Home, Vote, Leaderboard, Store, More).
  • ডান কোণায়: সার্চ আইকন, সক্রিয় মাইনক্রাফট প্লেয়ারের অ্যাভাটার হেড ও মোবাইল হ্যামবার্গার মেনু।

খ. স্ক্রল করার পর (Scrolled View - Scroll Y > 80px)

  • ইউজার ৮-১০% স্ক্রল করতেই পিলে থাকা স্ট্যাটাস চিপটি হালকা ফেড হয়ে বাম দিকে সরে যাবে (opacity: 0, transform: translateX(-10px)).
  • ঠিক সেই জায়গায় মিলিসেকেন্ডের ট্রানজিশনে আবির্ভূত হবে [HC Icon] HavenCraft ব্র্যান্ড লোগো (opacity: 1, transform: translateX(0)).
  • একই সাথে পিলটির দুই পাশ মসৃণভাবে প্রসারিত হয়ে ফুল-উইডথ আল্ট্রা-স্লিক গ্লাস হেডারে পরিণত হবে।

[!TIP] মাল্টি-পেজ সামঞ্জস্যতা (Multi-Page Harmony):
HavenCraft-এর অন্যান্য সাব-পেজে (/vote, /leaderboard, /store, /staff) যেহেতু কোনো হিরো লোগো নেই, তাই navbar.js স্বয়ংক্রিয়ভাবে শনাক্ত করবে—হোমপেজ ছাড়া অন্য সব পেজে ডিফল্টভাবেই ব্র্যান্ড লোগো সবসময় দৃশ্যমান থাকবে। ফলে অন্যান্য পেজের কোনো কোড ভাঙবে না!

5. হিরো সেকশন রিডিজাইন: Asymmetric Split Layout ব্লুপ্রিন্ট

// assets/js/hero-controller.js
(function () {
    'use strict';

    // 1. Adaptive Island Navbar on Scroll
    const navbar = document.getElementById('navbar');
    const heroTitle = document.querySelector('.hero-split-title');

    if (navbar && heroTitle) {
        // Using IntersectionObserver for optimal 60fps performance without scroll-lag
        const observer = new IntersectionObserver(
            ([entry]) => {
                if (!entry.isIntersecting) {
                    navbar.classList.add('scrolled');
                } else {
                    navbar.classList.remove('scrolled');
                }
            },
            { rootMargin: '-60px 0px 0px 0px' }
        );

        observer.observe(heroTitle);
    }

    // 2. Dual IP & Port Copy Helper
    window.copyServerIP = function (ip, element, port) {
        const fullAddress = port ? `${ip}:${port}` : ip;
        navigator.clipboard.writeText(fullAddress).then(() => {
            const badge = element.querySelector('.copy-badge');
            if (badge) {
                const originalHtml = badge.innerHTML;
                badge.innerHTML = '<i class="fa-solid fa-check"></i> Copied!';
                badge.classList.add('copied-success');
                setTimeout(() => {
                    badge.innerHTML = originalHtml;
                    badge.classList.remove('copied-success');
                }, 2000);
            }
        });
    };
})();
